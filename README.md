# HayPahest (ՀայՊահեստ) — ՓՄՁ Պահեստային և Վաճառքի Կառավարման Համակարգ

**HayPahest (ՀայՊահեստ)**-ը ամպային, առևտրային SaaS հարթակ է՝ ստեղծված հատուկ Հայաստանի Հանրապետության փոքր և միջին բիզնեսների (ՓՄՁ), խանութների, մեծածախ բազաների և առևտրային ցանցերի համար։

## 2. Ծրագրային Կառուցվածք (Architecture)

```
haypahest/
├── backend/                       # Python FastAPI Բեքենդ
│   ├── alembic/                   # Բազայի միգրացիոն սկրիպտներ
│   ├── app/
│   │   ├── api/v1/                # REST API Էնդփոյնթներ (auth, products, sales, inventory, subscriptions, reports)
│   │   ├── core/                  # Անվտանգություն, JWT, բացառություններ, թույլտվություններ
│   │   ├── models/                # SQLAlchemy 2.0 Օբյեկտային Մոդելներ
│   │   ├── schemas/               # Pydantic 2.0 Վալիդացիոն Սխեմաներ
│   │   ├── services/              # Բիզնես լոգիկա, գույքագրում, վճարումների ստորագրություն
│   │   ├── config.py              # Շրջակա միջավայրի կարգավորումներ (.env)
│   │   └── main.py                # FastAPI ծրագրի մուտքային կետ
│   ├── tests/                     # Ավտոմատացված ինտեգրացիոն թեստեր (pytest)
│   ├── Dockerfile                 # Բեքենդի կոնտեյներ
│   └── requirements.txt           # Python գրադարաններ
│
├── src/                           # React 19 + TypeScript Ֆրոնթենդ
│   ├── components/
│   │   ├── auth/                  # Մուտքի, գրանցման և դերային պաշտպանության բաղադրիչներ
│   │   ├── common/                # Ծանուցումներ, որոնում, շտրիխ-կոդերի սկաներ, անդորրագրեր
│   │   ├── layout/                # Sidebar, Header, UserProfileMenu
│   │   ├── products/              # Ապրանքների աղյուսակ, էջավորում, ֆորմաներ, քարտեր
│   │   ├── reports/               # Վերլուծական գրաֆիկներ (Recharts), տպագրական մոդալներ
│   │   ├── sales/                 # POS դրամարկղ, վճարման պատուհան, պատմություն
│   │   └── subscription/          # Սակագների համեմատություն, քվոտաներ, վճարման մոդալ
│   ├── context/                   # AppContext (վիճակի կառավարում) & AuthContext (նույնականացում)
│   ├── pages/                     # Համակարգի էջեր (Dashboard, Products, POS, Warehouse, Reports, և այլն)
│   ├── services/                  # API հաճախորդ, անալիտիկա, արտահանումներ, բաժանորդագրություն
│   ├── types/                     # TypeScript տիպեր և ինտերֆեյսներ
│   └── utils/                     # Ֆորմատավորում (ՀՀ դրամ ֏, ամսաթվեր, հաշվարկներ)
│
├── Dockerfile                     # Ֆրոնթենդի բազմափուլ (multi-stage) Nginx կոնտեյներ
├── docker-compose.yml             # Պրոդաքշն օրկեստրացում (PostgreSQL + Backend + Frontend + Backup)
└── package.json                   # Node.js փաթեթներ և կառուցման սկրիպտներ
```

## 3. Տեղադրում և Գործարկում (Local Development)

### 3.1 Ֆրոնթենդի (React SPA) Գործարկում

1. Տեղադրել Node.js (>= 18):
```bash
npm install
```

2. Գործարկել մշակման սերվերը (պորտ 3000):
```bash
npm run dev
```

3. Կառուցել պրոդաքշն տարբերակը:
```bash
npm run build
npm run lint
```

---

### 3.2 Բեքենդի (FastAPI) Գործարկում

1. Անցնել `backend` պանակ և ստեղծել վիրտուալ միջավայր:
```bash
cd backend
python3 -m venv venv
source venv/bin/activate # Windows-ում՝ venv\Scripts\activate
pip install -r requirements.txt
```

2. Կարգավորել միջավայրի փոփոխականները:
```bash
cp .env.example .env
```

3. Գործարկել տվյալների բազայի միգրացիաները (Alembic):
```bash
alembic upgrade head
```

4. Գործարկել սերվերը:
```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
* **Swagger Ինտերֆեյս**՝ `http://localhost:8000/docs`  
* **ReDoc**՝ `http://localhost:8000/redoc`

## 5. Ֆինանսական և Տվյալների Անվտանգություն

1. **Ճշգրտություն (Zero-Float Precision)**  
   Բոլոր ֆինանսական գործարքները (արժեքներ, գներ, զեղչեր, հարկեր, պարտքեր, հասույթ, շահույթ) հաշվարկվում են բացառապես ամբողջ ՀՀ դրամով (AMD integer)։
2. **Ատոմար Գործարքներ և Գերվաճառքի Կանխարգելում (POS Race Condition Defense)**  
   Վաճառքի գրանցման պահին պահեստի մնացորդը արգելափակվում է (`SELECT ... FOR UPDATE`), բացառելով միաժամանակյա երկու գանձապահների կողմից նույն ապրանքի գերվաճառքը։
3. **Բազմավարձակալային Իզոլացիա (Multi-Tenancy Isolation)**  
   Յուրաքանչյուր բիզնեսի տվյալները մեկուսացված են `business_id` բանալիով։ Անհնար է այլ ընկերության ապրանքների կամ հաշվետվությունների արտահոսքը։
4. **Սերվերային Իրավասություններ (RBAC)**  
   - `OWNER`՝ Ընկերության սեփականատեր (ամբողջական հասանելիություն, բաժանորդագրություն, ֆինանսներ, կարգավորումներ)։
   - `MANAGER`՝ Պահեստապետ/Մենեջեր (ապրանքներ, պահեստ, մուտք/ելք, վաճառքներ, հաշվետվություններ)։
   - `CASHIER`՝ Գանձապահ (միայն POS վաճառքներ, կտրոնների տպում և ապրանքների դիտում)։
5. **Վճարումների Ստորագրության Ստուգում (HMAC-SHA256)**  
   Բաժանորդագրությունների վճարումը չի ակտիվանում միայն ֆրոնթենդի կոճակով. սերվերը ստուգում է բանկի կրիպտոգրաֆիկ թվային ստորագրությունը։

## 7. Ֆունկցիոնալ Ստուգման և Պատրաստվածության Ամփոփում

- **Ամբողջությամբ Իրականացված և Թեստավորված**՝
  - Օգտատերերի մուտք, գրանցում, գաղտնաբառի վերականգնում, դերերի փոխարկում (Owner/Manager/Cashier)
  - Ապրանքների կատալոգ, ավելացում, խմբագրում, ջնջում, որոնում, զտում ըստ կատեգորիաների, տեսակավորում, էջավորում
  - POS դրամարկղ, շտրիխ-կոդերի որոնում/սկաներ, զամբյուղ, կանխիկի մանրի ավտոմատ հաշվարկ, քարտային և փոխանցմամբ վաճառք
  - Վաճառքի տեղեկանքների և կտրոնների տպում (Receipt Modal)
  - Պահեստային գործառնություններ (մուտք, տեղաշարժ, դուրսգրում, պլանային գույքագրման ակտ)
  - Հաճախորդների բազա, մանրածախ/մեծածախ տեսակներ, պարտքերի հաշվառում և մարում
  - Վերլուծական հաշվետվություններ (Հասույթ, ինքնարժեք/COGS, համախառն շահույթ, ապրանքների արդյունավետություն, աշխատակիցների վաճառքներ)
  - Տվյալների արտահանում Excel (.xlsx) և RFC 4180 համապատասխան CSV ձևաչափերով
  - Բաժանորդագրության 3 սակագնային պլան (START, BUSINESS, PRO), սահմանաչափերի (քվոտաների) վերահսկողություն
  - Գլոբալ որոնում (⌘K / Ctrl+K), տվյալների JSON արտահանում/ներմուծում
