# HayPahest (ՀայՊահեստ) — Production Python FastAPI Backend

Ամպային արտադրողական REST API նախագծված Հայաստանի փոքր և միջին բիզնեսների (ՓՄՁ) պահեստային հաշվառման, POS վաճառքների և ֆինանսական վերլուծության համար։

---

## 1. Տեխնոլոգիական Կույտ (Technology Stack)

- **Python 3.10+**
- **FastAPI** (Ասինխրոն, բարձր արագագործությամբ REST API)
- **SQLAlchemy 2.0** (Async Engine + DeclarativeBase)
- **Pydantic 2.0** (Տվյալների վալիդացիա և սխեմաներ)
- **PostgreSQL** (Ռելացիոն բազա `asyncpg` և `psycopg2-binary` դրայվերներով)
- **Alembic** (Բազայի ավտոմատացված միգրացիաներ)
- **Uvicorn** (ASGI սերվեր)
- **Pytest + Pytest-Asyncio + HTTPX** (Ավտոմատացված ինտեգրացիոն թեստեր)

---

## 2. Ֆինանսական և Անվտանգության Սկզբունքներ

1. **ՀՀ Դրամի Ամբողջական Հաշվարկ (Zero-Float Precision)**  
   Բոլոր գները, ինքնարժեքները, գումարները, զեղչերը և հարկերը պահվում և հաշվարկվում են բացառապես ամբողջ թվերով (Integer/BigInteger AMD)։ Տասնորդական float թվեր չեն օգտագործվում ֆինանսական սխալներից խուսափելու համար։

2. **Մրցավազքի Ռիսկերի Կանխարգելում (Race-Condition Free POS)**  
   Վաճառքի գրանցման պահին ապրանքի մնացորդի տողը արգելափակվում է տրանզակցիոն մակարդակում (`SELECT ... FOR UPDATE`), ապահովելով, որ միաժամանակյա գործարքների դեպքում ապրանքը չի կարող վաճառվել ավելին, քան փաստացի առկա է պահեստում։

3. **Multi-Tenant Իզոլացիա**  
   Յուրաքանչյուր ընկերության տվյալներ (ապրանքներ, պահեստներ, վաճառքներ, աշխատակիցներ) լիովին մեկուսացված են։ Բոլոր SQL հարցումները ստուգվում են `business_id` դաշտով։

4. **Սերվերային Դերային Հասանելիություն (Server-Side RBAC)**  
   - `OWNER` (Սեփականատեր) — Ամբողջական հասանելիություն
   - `MANAGER` (Մենեջեր) — Ապրանքների, պահեստի և աշխատակիցների կառավարում
   - `CASHIER` (Գանձապահ) — Վաճառքների իրականացում և ապրանքների դիտում

## 3. Տեղադրում և Գործարկում (Local Setup & Run)

### Քայլ 1․ Վիրտուալ միջավայրի ստեղծում

```bash
cd backend
python3 -m venv venv
source venv/bin/activate  # Windows-ում՝ venv\Scripts\activate
pip install -r requirements.txt
```

### Քայլ 2․ Կոնֆիգուրացիա (.env)

Պատճենեք օրինակելի ֆայլը և նշեք PostgreSQL միացման տվյալները.

```bash
cp .env.example .env
```

### Քայլ 3․ Բազայի Միգրացիաների Կիրառում (Alembic)

```bash
alembic upgrade head
```

### Քայլ 4․ Սերվերի Գործարկում (Uvicorn)

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

Սերվերը հասանելի կլինի `http://localhost:8000` հասցեով։  
- **Interactive Swagger Դոկումենտացիա**՝ `http://localhost:8000/docs`  
- **ReDoc Դոկումենտացիա**՝ `http://localhost:8000/redoc`  
- **Health Check Զոնդ**՝ `http://localhost:8000/health`

## 4. Ավտոմատացված Թեստերի Գործարկում (Testing)

Թեստերը գործարկվում են in-memory SQLite բազայի վրա և չեն պահանջում ակտիվ PostgreSQL.

```bash
pytest -v
```

Թեստային փաթեթը ստուգում է.
- `test_auth.py` — Օգտատիրոջ և ընկերության գրանցում, JWT ստուգում
- `test_products.py` — Ապրանքների ավելացում, արտիկուլների (SKU) կրկնության կանխում
- `test_inventory.py` — Պահեստի ճշգրտում, բացասական մնացորդի մերժում
- `test_sales.py` — Տրանզակցիոն վաճառք, մնացորդի նվազեցում, գերվաճառքի (oversell) կանխում
- `test_isolation.py` — Multi-tenant սահմաններ (Business A-ն չի տեսնում Business B-ի տվյալները)
- `test_permissions.py` — Դերային իրավասություններ (Գանձապահը չի կարող ջնջել ապրանքներ)
